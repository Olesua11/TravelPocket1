## Возможности
- список поездок;
- создание новой поездки;
- даты, страна и бюджет;
- экран маршрута по дням;
- бюджет поездки;
- карточка поездки;
- локальное хранение данных через Room;
- MVVM;
- RecyclerView;
- ViewBinding;

## Стек
Kotlin, XML, Material 3, Room, MVVM, Coroutines/Flow, RecyclerView, ViewBinding.
